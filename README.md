## 1.项目框架
- code： 代码
- dataset： 数据集目录
- output： 数据预处理后结果

- log： 模型训练日志
- model： 训练的模型

  1. 数据预处理（切片、STFT）
  2. 神经网络训练（CNN)

  - CNN_train： CNN模型训练
